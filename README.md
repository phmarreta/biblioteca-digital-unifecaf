# 📚 Biblioteca Digital UniFECAF

## Sobre o projeto

A **Biblioteca Digital UniFECAF** é um projeto acadêmico desenvolvido para a faculdade UniFECAF, com o objetivo de criar uma página web para apresentar uma biblioteca digital de forma simples, organizada e acessível.

O projeto foi desenvolvido utilizando HTML e CSS, aplicando conceitos fundamentais de desenvolvimento web, estruturação de páginas e estilização de interfaces.

## 🎯 Objetivos

- Desenvolver uma página web para uma biblioteca digital.
- Praticar os fundamentos de HTML e CSS.
- Organizar os arquivos e recursos do projeto.
- Criar uma interface adaptável para computadores e dispositivos móveis.
- Aplicar os conhecimentos adquiridos no curso de Análise e Desenvolvimento de Sistemas (ADS).

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação do conteúdo da página.
- **CSS3:** estilização e organização visual da interface.
- **Git e GitHub:** versionamento e hospedagem do código-fonte.
- **GitHub Pages:** publicação do site na web.

## 💻 Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.
4. Navegue pela página para visualizar a interface da biblioteca digital.

## 🌐 Publicação

O projeto pode ser publicado gratuitamente utilizando o GitHub Pages.

Após a configuração da publicação, o endereço do site ficará disponível na seção **About** do repositório.
